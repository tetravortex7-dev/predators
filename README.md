# Evo — Adapt. Win.

**English** · **[Русский](#evo--адаптируйся-побеждай)**

A custom Dota 2 Arcade mode where survival depends on constant adaptation. Begin as a fragile primordial form, evolve through distinct creature paths, and clash in a dynamic multi-biome arena where every match unfolds differently.

---

## Evo — Адаптируйся. Побеждай.

**[English](#evo--adapt-win)** · **Русский**

Кастомный игровой режим для Dota 2, где победа зависит от постоянной адаптации. Начните путь в хрупкой первичной форме, эволюционируйте в новые виды и сражайтесь в изменчивой арене среди разных биомов, где каждый матч складывается по-новому.
